# Tg-trending — Telegram-бот «ИИ-аналитик» для крипторынка

Бот разбирает монету по тикеру, адресу контракта или вопросу своими словами.
Он параллельно опрашивает **130+ источников без ключей** (всего в каталоге 233),
собирает отчёт и даёт вывод через Claude. Ещё в боте есть слежки за ценой и
«навыки»: 8 встроенных (в том числе теханализ и тейки), которые работают даже без ключа ИИ, и свои — сохранённые
правила и шаблоны ответа.

```
✱ Trending · ИИ-аналитик

Запас на сегодня ▰▰▰▰▰▰▰▰▱▱ 76%
Слежки — пока нет

Напиши тикер или вопрос — начну разбор.

[ ✱ Разобрать монету ]
[ 🔔 Слежки ] [ 🧠 Навыки ]
[ 👤 Профиль ] [ ❓ Помощь ]
```

## Что умеет каркас

| Экран | Что делает |
|---|---|
| ✱ **Разобрать монету** | Экран с подсказкой и кнопками 🔥 «чаще всего спрашивают за 12 ч» (по статистике запросов, недостающие дополняются ⭐ популярными монетами) |
| Свободный текст | `BTC`, `$HYPE`, `сравни ARB и OP`, адрес `0x…` / Solana / TON, `что на рынке?` |
| Ответ | **Картинка-карточка** с ценой, графиком за 7 дней и главными метриками + **живой текст** с выделенными цифрами (пишет ИИ, без ключа — шаблон). Под кнопкой «📋 Подробно» — полный отчёт: биржи и спред, фандинг и OI, L/S, опционы, DEX, TVL, ончейн, соцсети, новости, рыночный фон, рой агентов |
| Контракт | Ликвидность, объём, сделки, возраст пула, держатели и концентрация, **проверка на скам** (GoPlus, Honeypot.is, RugCheck) |
| 🔔 **Слежки** | `BTC > 120000`, `ETH < 3000`, `SOL ±5%`, `TON +10%`; фоновая проверка раз в минуту и уведомление со ссылкой на разбор |
| 📊 **Скринер** | Списки монет по всему рынку, без ИИ и без расхода запаса: 🔥 фандинг (где перегреты лонги и шорты, Binance + Bybit, ставка приведена к 8 ч), 🚀 рост и 📉 падение за сутки (топ-250 CoinGecko, при лимите — Binance), 📊 аномальный объём (оборот относительно капы), 🆕 новые фьючерсы за 2 недели. Кнопка на экране «Разобрать монету», `/screener` или словами: «где самый высокий фандинг», «что растёт», «новые листинги» |
| 🧠 **Навыки** | Встроенные (бот считает сам, без ключа ИИ): 🎯 тейки, 📐 теханализ, 📰 новости, 🌡 перегрев, ⚖️ риск, 💱 арбитраж, ⚡ коротко, 🛡 скам-чек. Свои — правила или шаблон («тейки», «мой стиль») для промпта ИИ. Вызов: «разбери BTC навык перегрев» или «#перегрев» |
| 👤 **Профиль** | Запас на сегодня, число разборов, навыков и слежек |
| ❓ **Помощь** / `/sources` | Справка и статистика источников по категориям |

Под отчётом есть кнопки «🔔 Следить», «🔄 Обновить» и «📊 Источники» (кто ответил, а кто нет).

Пока идёт разбор, бот «думает» — как ИИ-чат: одно компактное сообщение с бегущими точками
и таймером, а сверху «печатает…»:

```
✱ Думаю...
⏱ 6 с
```

Как только ИИ начинает писать ответ, текст **идёт в чат прямо по мере генерации**. В личке —
через нативный черновик Telegram (`sendMessageDraft`, как у ИИ-ботов): «Думаю…» и ответ живут
в одном «пузыре», а клиент Telegram сам плавно анимирует каждое обновление, без рывков правок.
Когда текст дописан, бот отправляет одно сообщение: картинка с цифрами сверху, под ней этот же
текст и кнопки — черновик при этом исчезает (картинка рисуется заранее, пока пишется текст). Для Claude это потоковый API (с запасной
моделью при отказе), для OpenAI-совместимых — SSE-поток. Без ключа ИИ готовый текст по шаблону
пишется так же плавно.

В группах черновиков нет — там подпись под карточкой дописывается правками (на конце курсор ▍,
не чаще раза в 2.5 с из-за лимитов Telegram). Если сервер Telegram черновик не примет, бот
один раз напишет об этом в лог и дальше сам перейдёт на правки.

Настройки: `STREAM_ANSWERS=false` — показывать ответ сразу целиком; `STREAM_DRAFTS=false` —
в личке тоже правками; `DRAFT_INTERVAL` (0.25 с) — пауза между обновлениями черновика;
`STREAM_INTERVAL` (0.7 с) — между правками.
Синие кнопки сделаны через `style="primary"` (Bot API 9.4+).

## 🖼 Оформление ответа

Ответ приходит одним сообщением: сверху картинка с цифрами, под ней живой текст —
как пишет аналитик в чате, ключевые цифры выделены жирным.

| Запрос | Карточка |
|---|---|
| `что на рынке?`, `что пишут?` | **Рынок · 24ч**: топ-20 монет (цена, 24ч), страх и жадность, капитализация и доля BTC |
| `BTC`, `разбери SOL` | монета: цена, изменение, график за 7 дней, плитки (капа, фандинг, открытый интерес, страх и жадность, DVOL/DEX/TVL/ончейн) |
| адрес контракта | токен: цена, график пула, ликвидность, объём, FDV, сделки, возраст пула, риск и красные флаги |
| `сравни ARB и OP` | таблица метрик и графики изменения за 7 дней в % |

В углу карточки — название бота и QR-код со ссылкой на него. Время — в часовом поясе
`TIMEZONE` (например, `Europe/Kyiv`). Полный построчный отчёт открывается кнопкой «📋 Подробно».
Вернуть старый вид (один текстовый отчёт): `REPORT_STYLE=text`. Если картинку не удалось
нарисовать, бот сам пришлёт текстовый отчёт.

Шрифт Inter (лицензия SIL OFL 1.1) лежит в `bot/render/fonts/`, поэтому карточки выглядят
одинаково на любом сервере.

## 👥 В группах

Бот работает и в чатах. Кнопка «➕ Добавить в чат» в разделе «Помощь» сразу предлагает
выбрать группу. В группе бот молчит, пока его не позовут, и отвечает реплаем на:

- упоминание: `@имя_бота разбери BTC`;
- ответ на любое его сообщение: «а что по ETH?»;
- команду `/ask BTC`.

Запас считается по каждому пользователю. Пересланные посты (текст или подпись к картинке)
бот тоже разбирает: найдёт в них тикеры и ответит по сути поста.

Личное в группе не показывается:
- `/start` в группе даёт общее меню без запаса и слежек.
- Кнопки «Навыки», «Слежки», «Профиль», «Следить за BTC» и команда `/profile` открывают
  личный чат с ботом сразу на нужном разделе (ссылка `t.me/<бот>?start=<раздел>`).
  Создавать навыки и слежки можно только там.
- «🔄 Обновить» и «📊 Источники» относятся к отчёту, под которым нажаты, а не к последнему
  запросу нажавшего.

⚠️ По умолчанию у ботов в группах включён режим приватности, и упоминания до бота
**не доходят** — работают только `/ask` и ответы на его сообщения. Чтобы бот видел
упоминания: в @BotFather → `/setprivacy` → выбрать бота → **Disable**, затем удалить
бота из группы и добавить снова. Другой способ — сделать бота админом группы.

Ссылки в «Помощи» настраиваются в `.env`: `SUPPORT_URL` (кнопка «💬 Поддержка») и
`RULES_URL` («Правила использования»). Если ссылка не задана, кнопка или строка не показывается.

## 📷 Разбор скриншота графика

Пришли в личку картинку с графиком (фото или файлом JPG/PNG/WEBP/GIF до 5 МБ), можно с
подписью: «SOL 4ч, что думаешь?». ИИ прочитает график — тренд, фигуры, индикаторы, уровни
со шкалы. Если в подписи есть тикер, бот добавит к картинке свежий теханализ и сетап по
свечам бирж, и модель сверит скриншот с реальной ценой. Ответ идёт по мере генерации.

Нужна модель, которая видит картинки: Claude, GPT или Gemini. По умолчанию это главный
аналитик (`LLM_MODEL`); если он не умеет картинки (например, DeepSeek), укажи
`VISION_MODEL`. Без ключа ИИ подпись к фото разбирается как обычный вопрос.

## 🐝 Рой агентов

Вместо одного ИИ разбор делает команда специалистов. Каждый получает **только свою
часть данных**, агенты работают параллельно, а главный аналитик сводит их выводы в итог.

**Рой по требованию.** Рой — это до 6 вызовов ИИ на вопрос, поэтому по умолчанию
(`AI_MODE=auto`) он работает только там, где разные взгляды реально помогают:

| Когда зовётся рой | Пример |
|---|---|
| просят подробно | «разбери BTC подробно», «детально», «роем» |
| сравнение | «сравни ARB и OP» |
| проверка токена по контракту | `0x…` |
| свой навык | «разбери SOL навык тейки» |
| вопрос о решении | «стоит ли покупать ETH», «лонг или шорт», «прогноз» |
| развёрнутый вопрос | от 8 слов |

На простой «разбери BTC» или «что с SOL» отвечает один главный аналитик — в 3–5 раз
дешевле и быстрее. «Коротко», «кратко», «быстро» — всегда без роя. `AI_MODE=always` —
рой на каждый вопрос, `AI_MODE=single` — без роя (старое `swarm` работает как `auto`).

| Агент | Его данные |
|---|---|
| 🏦 Трейдер | цена, объёмы, биржи и спред, ATH, DEX-пулы, макро |
| 📈 Деривативщик | фандинг по биржам, OI, L/S, taker buy/sell, DVOL, put/call |
| ⛓ Ончейн-аналитик | MVRV, адреса, комиссии, хешрейт, TVL, выручка протокола |
| 📰 Новостник | новости, Reddit, 4chan, StockTwits, Fear & Greed |
| 🛡 Риск-менеджер | только для контрактов: проверки на скам, ликвидность, держатели |
| 🤖 Главный аналитик | выводы агентов + все данные + навыки пользователя → итог |

Каждый агент отвечает строгим JSON: сигнал 🟢/🟡/🔴, уверенность, главный вывод
с цифрой и 2–3 пункта. Если данных по роли нет (например, ончейна у мемкоина),
агент не запускается и не тратит запрос. Агент, который не ответил за 45 с или
упал, не ломает разбор: можно задать запасную модель (`SWARM_FALLBACK_MODEL`).

```
🐝 Рой агентов · ответили 4 из 4 · 🟢 2 · 🟡 1 · 🔴 1
🏦 Трейдер 🟢 Импульс вверх: +9,5% за сутки при объёме $50B
📈 Деривативщик 🔴 Лонги перегреты: фандинг +0,04%/8ч на 9 биржах
⛓ Ончейн-аналитик 🟡 MVRV 2,1 — оценка выше средней, но не перегрета
📰 Новостник 🟢 Фон позитивный, F&G 72 — жадность
▸ подробности (свёрнуто)

🤖 Итог
…
```

**Модели.** По умолчанию агенты работают на Claude Haiku 5.5 (быстро и дёшево),
итог пишет Claude Opus 5.5. Любую роль можно отдать другому ИИ — строкой
`провайдер:модель` в `.env`:

```bash
SWARM_AGENT_MODEL=claude-haiku-5-5            # все агенты
SWARM_MODEL_DERIVATIVES=deepseek:deepseek-chat   # отдельная роль — другой ИИ
SWARM_MODEL_NEWS=openrouter:<автор>/<модель>
SWARM_FALLBACK_MODEL=gemini:<модель>          # если агент не ответил
LLM_MODEL=claude-opus-5-5                     # главный аналитик
```

Поддерживаются Claude и любой OpenAI-совместимый API: OpenAI, DeepSeek, xAI (Grok),
Mistral, Gemini, Groq, OpenRouter, Ollama и свой сервер (`custom:` + `CUSTOM_AI_BASE_URL`).
Ключи — в `.env` (`OPENAI_API_KEY`, `DEEPSEEK_API_KEY`…). Роль без доступного ключа
уходит на модель по умолчанию.

## Установка на VPS (одной командой)

Подойдёт сервер на Ubuntu 22.04/24.04, Debian 11/12 или Alma/Rocky 8–9 с root-доступом,
желательно от 1 ГБ RAM. Входящие порты открывать не нужно: бот сам забирает
сообщения из Telegram (long polling).

```bash
ssh root@АДРЕС_СЕРВЕРА
```

```bash
curl -fsSL https://raw.githubusercontent.com/gytfel/Tg-trending-/refs/heads/main/deploy/install.sh -o install.sh
```

```bash
sudo bash install.sh
```

> Пока код не слит в `main`, укажи ветку: в адресе выше замени `main` на имя ветки
> и запускай `sudo BRANCH=имя-ветки bash install.sh`.

Скрипт спросит токен бота (от @BotFather), ключ Claude (можно пропустить) и твой
Telegram ID для админ-доступа. Потом он сам:

1. ставит git, curl и Python. Если системный Python старше 3.11 (например, Ubuntu 22.04),
   рядом ставится отдельный Python 3.12 через uv — системный не трогается;
2. скачивает код в `/opt/tg-trending` и ставит зависимости в `.venv`;
3. создаёт системного пользователя `tgbot`: бот работает не от root и может писать только в `data/`;
4. записывает `.env` (права 640) и проверяет токен через Telegram;
5. регистрирует systemd-сервис `tg-trending`: автозапуск при перезагрузке и перезапуск при сбое;
6. проверяет, какие источники данных доступны с этого сервера.

Запускать скрипт повторно безопасно: он обновит код и зависимости, а `.env` и базу не тронет.
Без вопросов, например из CI:

```bash
sudo BOT_TOKEN=123456:AAH... ANTHROPIC_API_KEY=sk-ant-... ADMIN_IDS=111222333 bash install.sh
```

Управление после установки:

| Команда | Что делает |
|---|---|
| `tg-trending status` | работает ли бот |
| `tg-trending logs` | логи в реальном времени (выход — Ctrl+C) |
| `tg-trending restart` / `stop` / `start` | перезапуск, остановка, запуск |
| `tg-trending config` | открыть `.env` в редакторе и перезапустить |
| `tg-trending update` | подтянуть новую версию с GitHub и перезапустить |
| `tg-trending probe BTC` | проверить источники данных с сервера |
| `tg-trending uninstall` | удалить сервис (код и база останутся) |

⚠️ С одним токеном может работать только одна копия бота. Если бот запущен и на
компьютере, и на сервере, Telegram выдаст ошибку `Conflict: terminated by other getUpdates request`.

## Быстрый старт (локально)

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN от @BotFather, по желанию ANTHROPIC_API_KEY
python -m bot
```

Через Docker:

```bash
cp .env.example .env
docker compose up -d --build
```

Обязателен только `BOT_TOKEN`. Без ключа ИИ бот работает целиком: вывод строится
по простым правилам, встроенные навыки считаются, а свои навыки не применяются.
Где взять каждый ключ (ИИ и источники данных) — ссылка над ним в `.env.example`.

### 🧠 Встроенные навыки

Их не нужно создавать — достаточно позвать в вопросе: «разбери BTC навык перегрев»
или «BTC #перегрев». Бот считает их сам по собранным данным, поэтому они работают и
без ключа ИИ: результат идёт в подпись под карточкой (сколько влезет в лимит
Telegram) и целиком — в «📋 Подробно».

Теханализ и тейки срабатывают и без слова «навык»: «тейки по BTC», «уровни ETH», «RSI SOL»,
«точка входа». Свечи 4ч и 1д берутся с Binance (запасной — Bybit) только для этих навыков.

| Навык | Что считает |
|---|---|
| 🎯 **тейки** (сетап) | сетап по тренду: вход (по рынку или на откате к уровню, если RSI перегрет), стоп за ближайшим уровнем с запасом пол-ATR (не ближе 1 ATR и не дальше 3 ATR), три тейка на уровнях с R:R от 1 или по R-кратным, условие отмены |
| 📐 **теханализ** (та) | тренд по EMA 50/200 на дневках и EMA 20/50 на 4ч, RSI 4ч и 1д, пересечение MACD, ATR, всплеск объёма, ближайшие уровни поддержки и сопротивления (развороты 4ч и 1д) |
| 📰 **новости** (news) | 5 свежих заголовков по монете со ссылками, тон заголовков (рост/падение/нейтрально), соцсети, страх и жадность |
| 🌡 **перегрев** (фандинг) | фандинг по биржам (выше и ниже всех), OI, L/S аккаунтов и топ-трейдеров, taker buy/sell, Put/Call, DVOL → кто перегрет и риск сквиза |
| ⚖️ **риск** (позиция) | размер позиции под депозит и риск на сделку для 3 стопов от обычного дневного хода монеты, нужно ли плечо, хватит ли ликвидности. Цифры берутся из вопроса или своих навыков: «депозит 2000 риск 2% стоп 5%» (без депозита — на $1 000) |
| 💱 **арбитраж** | где дешевле и дороже (биржи с объёмом от $50K), разница против комиссий ~0.3%, разница USD/USDT, цена на DEX |
| ⚡ **коротко** | три строки: что происходит, что важно, за чем следить (границы недели по свечам) |
| 🛡 **скам-чек** (скам) | флаги контракта, ликвидности, возраста пула, держателей — от самых опасных, и вердикт 🔴/🟠/🟢 |

С ключом ИИ навык ещё и уходит в промпт: инструкция + цифры, которые посчитал бот,
— модель опирается на них, а не считает заново. Свой навык с именем встроенного
заменяет его инструкцию для ИИ, но цифры бота всё равно добавляются.

### Проверка источников без Telegram

```bash
python -m bot.sources.probe BTC -v          # все источники по тикеру, что вернул каждый
python -m bot.sources.probe 0x6982508145454Ce325dDbE47a25d4ec3d2311933   # контракт
python -m bot.sources.probe --global        # общий фон рынка
python -m bot.sources.probe BTC --only binance,okx,coingecko -v
```

Запускай это на сервере, где будет жить бот: так сразу видно, какие API
доступны из его сети. Сломавшийся источник выключается без правки кода:
`DISABLED_SOURCES=id1,id2`.

Как работает сбор:

* Все источники одного запроса опрашиваются **параллельно**: на каждый 8 с, на весь сбор 15 с.
  Медленные отменяются, а ответ дописывается в кеш для следующих запросов.
* Общий HTTP-клиент с **TTL-кешем** и склейкой одинаковых запросов: если 50 человек
  одновременно спросили BTC, к Binance уйдёт один запрос.
* Ответы приводятся к общим типам (`Quote`, `Market`, `Derivatives`, `DexPair`,
  `NewsItem`, `Metric`, `Security`), а `Snapshot` считает агрегаты: медианную цену,
  спред с отбросом выбросов, средний фандинг, суммарный OI.
* Для **контрактов** CEX по тикеру не опрашиваются: у мемкоина может оказаться
  тикер чужой крупной монеты.

### Как добавить источник

Нужна одна функция в подходящем модуле `bot/sources/providers/`:

```python
@source("mybourse", "MyBourse", category=Category.CEX, scope=Scope.SYMBOL,
        homepage="https://mybourse.com", when=not_quote("USDT"))
async def mybourse(ctx: Ctx):
    d = await ctx.http.get_json("https://api.mybourse.com/ticker", {"pair": f"{ctx.sym}_USDT"})
    return Quote(price=need(d["last"]), change_24h=num(d["change"]), volume_24h=num(d["quoteVol"]))
```

* `scope`: `SYMBOL` — тикер, `CONTRACT` — адрес, `TOKEN` — то или другое,
  `ANY` — с монетой или без (новости), `GLOBAL` — фон рынка.
* Если нужен ключ, передай `key="MYBOURSE_API_KEY"`: источник включится, как только
  переменная появится в `.env`, а сам ключ придёт в `ctx.key`.
* «Нет такой пары» — это `raise NoData(...)` или ответ 400/404, а не ошибка.
* Для источника из планов: замени `planned(...)` на функцию с `@source`.

## Архитектура

```
bot/
  app.py             сборка: настройки, БД, HTTP, реестр, Claude, диспетчер, фоновые слежки
  handlers/          экраны: menu (старт, профиль, помощь), analyze, skills, watches, screener, chart (скриншоты)
  keyboards.py texts.py callbacks.py states.py
  query_parser.py    тикеры, кэштеги, контракты, «сравни», «навык X»
  db.py              SQLite: users, usage (запас), skills, watches, queries (тренды)
  services/
    analyzer.py      конвейер: запрос → активы → сбор → отчёт → вывод
    report.py        подробный отчёт (Telegram HTML), сравнение, контекст для ИИ
    cards.py         данные для карточек из собранных снимков
    prose.py         живой текст под карточкой (без ИИ)
    skills_builtin.py встроенные навыки: новости, перегрев, риск, арбитраж, коротко, скам-чек
    screener.py      скринер рынка: фандинг, рост/падение, объёмы, новые листинги
    ta.py            теханализ: свечи 4ч/1д, EMA, RSI, MACD, ATR, уровни, сетап с тейками
    swarm.py         рой агентов: роли, нарезка данных, параллельный запуск, блок отчёта
    llm.py           главный аналитик (итог; учитывает выводы роя и навыки)
    watches.py       разбор условий, проверка, фоновый Watcher
    prices.py quota.py trending.py
  ai/
    providers.py     Claude + OpenAI-совместимые API, «провайдер:модель», AIHub
  sources/
    base.py          типы данных и DataSource
    registry.py      @source / planned(), выборки по активу
    collector.py     параллельный сбор → Snapshot с агрегатами
    http.py          aiohttp + TTL-кеш + склейка запросов
    resolver.py      тикер → CoinGecko id/имя; контракт → сеть/тикер (DexScreener)
    providers/       cex, derivatives, aggregators, dex, defi, onchain,
                     security, sentiment, news, social, macro
    probe.py         CLI-проверка и генерация каталога
  render/
    cards.py         рисует карточки (Pillow): рынок, монета, контракт, сравнение
    fonts/           шрифт Inter + лицензия OFL
deploy/

  manage.sh          команда tg-trending: status, logs, update, config, probe…
```
